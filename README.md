# Westie Desk Pet 🐶🎾

一款原生轻量化 **macOS 西高地白梗（Westie）桌面陪伴 + 2.5D 网球对打** 小应用（Swift 6 + AppKit + SpriteKit，安装包体积 < 2 MB，无需辅助功能或录屏权限）。

平时它是一只像素风西高地小狗，会自动沿着你打开的各个窗口顶边散步、歪头坐下、打盹或跨窗口跳跃；想放松一局时，随时展开半透明桌面网球场，用 **`WASD` + 鼠标** 和戴着网球头带的西高地来一场 5 分制网球对决！

---

## ✨ 核心特性

### 1. 桌面窗口陪伴模式（零打扰 · 自动跟随当前窗口）
- **零权限活动窗口感知**：基于 `CGWindowListCopyWindowInfo` + `NSWorkspace` 实时追踪当前激活的前台窗口与全屏状态，不申请录屏或辅助功能权限。
- **双场景智能陪伴位（全屏 vs 非全屏）**：
  - **非全屏窗口模式**：当你切换或移动当前活动窗口时，西高地会自动平滑跟到当前窗口的 **正上方上沿**（自动避开左上角红黄绿窗口按钮，安静散步、趴卧或托腮发呆）以及 **窗口右上侧边框探头位**（通过裁剪遮罩从窗口右后方探出小脑袋，绝不遮挡窗口正文与滚动条）。
  - **全屏模式（含原生 macOS 全屏桌面）**：自动跑到 **屏幕最右侧边缘** 探出半个可爱狗头；平时静静陪伴不晃动，鼠标移过去时会平滑探出脑袋挥爪互动，移开自动缩回。
  - **零侵入办公体验**：去除浮夸飞爱心与剧烈晃头动效，鼠标经过标题栏或窗口边缘绝不干扰办公视线。
  - **交互操作**：
    - **左键拖拽**：可将小狗拎到窗口正上方、窗口右侧探头位，或在全屏右侧上下调整探头高度。
    - **右键快捷菜单 / 顶部菜单栏图标**：一键切换 `移到当前窗口正上方` / `移到右侧探头`、设置陪伴位置偏好、调整网球球速、投喂骨头饼干 `🦴`、切换安静趴睡模式 `💤` 或开始打网球 `🎾`。
  - **专注邀战 & 会议免打扰**：检测到 Teams / Zoom 前台开会时自动安静趴睡；连续工作一段时间后会叼着绿色网球冒出 `🎾 来打网球!` 气泡。

### 2. 2.5D 桌面网球模式（`WASD` + 鼠标对打 · 四档球速调节）
- **GBA《马里奥网球》风格半透明球场**：直接在桌面中央展开，支持完整三维 `(x, y, z)` 重力、球网高度判定、旋转空气动力与单打边线/二跳得分规则。
- **四档球速可调（默认慢速轻松上手）**：内置 **`🐢 慢速 (默认)` / `🎾 适中` / `⚡️ 标准` / `🔥 快速`** 四档球速并自动记忆，可通过球场顶部按钮、快捷键 `[-]` / `[+]`（或 `[` / `]`）或右键菜单随时切换。
- **操作指南（兼容中文输入法，基于硬件键码）**：
  | 操作 | 效果 |
  | :--- | :--- |
  | **`W / A / S / D`**（或方向键） | 控制底线球员前后左右跑位 |
  | **双击方向键 / `Space`** | 飞身冲刺救大角度球 |
  | **鼠标移动** | 移动对面半场的落点准星 |
  | **鼠标左键点按** | 快速平击抽球 / 发球 |
  | **鼠标左键按住蓄力松开** | 强力上旋抽球（过网急坠、落地加速） |
  | **鼠标右键点击** | 瞄近网为 **切削放小球（Drop Shot）**；瞄底线为 **高吊球（Lob）** |
  | **`-` / `=`（或 `[` / `]` / 顶部球速按钮）** | 实时调慢 / 调快网球速度 |
  | **`R` / 左键（赛末）** | 重新开球再来一局 |
  | **`ESC` / 右上角按钮 / `⌘⇧T`** | 立即收起球场，西高地回到当前活动窗口陪伴位 |
- **双难度西高地 AI**：可在球场左上角或菜单栏切换 **休闲小狗 (Casual)** 与 **网球狗王 (Pro，带飞身扑救与放小球战术)**。

## 🚀 构建与运行

环境要求：**macOS 14.0+**，安装 Xcode 或 Xcode Command Line Tools（Swift 6.0+）。

```bash
# 1. 运行内置物理、AI 与贴图资源自检
swift run WestieDeskPet --self-test

# 2. 打包独立 macOS 应用 (输出到 dist/WestieDeskPet.app)
./scripts/build_app.sh

# 3. 启动西高地桌面伙伴！（启动后常驻顶部菜单栏，不占 Dock 图标）
open dist/WestieDeskPet.app
```

也可以直接通过命令行参数直接进入网球模式调试：

```bash
swift run WestieDeskPet --tennis
```

## 🎨 AI 像素美术资产管线（Azure GPT-Image-2.5）

所有 22 张透明背景像素精灵（含边缘探头、安静趴卧、网球挥拍等姿态）与菜单栏/应用图标均由 `scripts/generate_assets.py`、`scripts/generate_peek_sprites.py` + `scripts/process_sprites.py` 自动生成与切图对齐（使用参考图锁定同一只蓝项圈西高地的角色一致性）：

```bash
export AZURE_OPENAI_ENDPOINT="https://<your-resource>.openai.azure.com"
export AZURE_OPENAI_API_KEY="<your-api-key>"

uv run --with pillow --with numpy python scripts/generate_assets.py
uv run --with pillow --with numpy python scripts/process_sprites.py
```
